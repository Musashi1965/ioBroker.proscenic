# Security Policy

## Supported versions

There is no released adapter version yet. Supported release lines will be
listed here after the first publication.

## Reporting a vulnerability

Once the GitHub repository is public, use GitHub private vulnerability
reporting. Do not open a public issue containing credentials, tokens, serial
numbers, device or gateway addresses, maps, packet captures, logs, or exploit
details that would expose an installation.

If private reporting is not available, contact the repository owner without
including secrets and request a private channel.

## Handling sensitive data

Reports and fixes must use redacted logs and neutral fixtures. Credentials and
session tokens must never enter commits, issues, pull requests, CI artifacts,
release packages, or ordinary ioBroker states.
